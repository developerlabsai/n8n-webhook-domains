# Claude Configuration for This Project

This directory contains project-specific configuration for Claude Code and Claude Desktop.

## Files

### `settings.local.json`
Project-specific permissions for Claude Code. This file configures which bash commands can run without asking for permission.

**Current permissions:**
- Git operations (add, commit, push)
- File permissions (chmod)
- GitHub operations (gh repo create)

### `mcp-config-template.json`
Template for configuring MCP servers in Claude Desktop. This is a template file that needs to be customized with your actual values:

- Replace `YOUR_EC2_IP_OR_DOMAIN` with your EC2 instance IP
- Replace `/path/to/your-key.pem` with your actual SSH key path
- Replace `ABSOLUTE_PATH_TO_THIS_PROJECT` with the full path to this project
- Replace `us-east-1` with your AWS region if different

### `mcp-config.json` (Generated)
**⚠️ This file is generated by `setup-mcp.sh` and contains sensitive data**

This file is automatically added to `.gitignore` and should **never** be committed to version control.

## Using MCP Servers (Claude Desktop Only)

### Quick Setup

Run the automated setup script:
```bash
./scripts/setup-mcp.sh
```

This will:
1. Install required MCP servers globally via npm
2. Prompt you for your EC2 IP, SSH key path, and AWS region
3. Generate the MCP configuration
4. Save it to your Claude Desktop config

### Manual Setup

1. **Install MCP Servers:**
   ```bash
   npm install -g @modelcontextprotocol/server-aws
   npm install -g @modelcontextprotocol/server-ssh
   npm install -g @modelcontextprotocol/server-docker
   npm install -g @modelcontextprotocol/server-filesystem
   ```

2. **Copy template and customize:**
   ```bash
   cp mcp-config-template.json mcp-config.json
   # Edit mcp-config.json with your actual values
   ```

3. **Add to Claude Desktop:**

   Edit `~/Library/Application Support/Claude/claude_desktop_config.json`

   Copy the contents of `mcp-config.json` into the `mcpServers` section.

4. **Restart Claude Desktop**

### Verifying Setup

In Claude Desktop, try these commands:
- "What is the status of my EC2 instance?"
- "Show me my security group rules"
- "Check if Docker is installed on my server"

If MCP is working, Claude will be able to answer these questions directly.

## Security Notes

- Never commit `mcp-config.json` to version control
- SSH keys should have restricted permissions: `chmod 400 /path/to/key.pem`
- Use AWS IAM roles with minimal required permissions
- Regularly rotate SSH keys and AWS credentials

## Troubleshooting

### MCP Servers Not Working

1. Check if installed:
   ```bash
   npm list -g @modelcontextprotocol/server-aws
   ```

2. Restart Claude Desktop completely (Quit, not just close window)

3. Check Claude Desktop config syntax:
   ```bash
   cat ~/Library/Application\ Support/Claude/claude_desktop_config.json | jq
   ```

### SSH Connection Failed

1. Test SSH manually:
   ```bash
   ssh -i /path/to/key.pem ubuntu@your-ec2-ip
   ```

2. Check key permissions:
   ```bash
   chmod 400 /path/to/key.pem
   ```

3. Verify EC2 security group allows SSH from your IP

### AWS Credentials Issues

1. Verify credentials:
   ```bash
   aws sts get-caller-identity
   ```

2. Reconfigure if needed:
   ```bash
   aws configure
   ```
